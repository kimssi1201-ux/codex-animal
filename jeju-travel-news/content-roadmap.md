# 제주여행뉴스 콘텐츠 운영 로드맵

목표: 얇은 자동 글을 대량 발행하지 않고, 같은 상세 템플릿으로 100개 글을 순차 제작한다.

## 글 템플릿

모든 글은 아래 순서로 작성한다.

1. 제목: 장소명 + 검색 의도 + 핵심 정보
2. 한 줄 요약
3. 기본 정보: 지역, 주소, 주차, 운영시간, 입장료
4. 이런 사람에게 추천
5. 권장 동선
6. 본문 정보
7. 여행 코스 요약
8. 방문 전 체크포인트
9. 주변 추천
10. 관련 글

## 제목 규칙

- 장소 글: `장소명 주차 운영시간 입장료 여행 코스 정리`
- 코스 글: `지역명 반나절 코스 주차 카페 맛집 동선`
- 날씨 글: `비 오는 날 제주 지역명 실내 여행 코스`
- 가족 글: `아이와 가기 좋은 제주 여행지 주차 동선 정리`

## 운영 기준

- 하루에 여러 글을 자동 발행하지 않는다.
- 같은 문장 구조를 반복하지 않는다.
- 최소 1개 이상의 실제 판단 정보를 넣는다: 주차 난이도, 추천 시간대, 누구에게 맞는지, 대체 코스.
- 관광공사 API 값은 보조 정보로 쓰고, 본문은 독자 관점으로 다시 정리한다.
- Search Console에서 노출이 생긴 글부터 제목과 본문을 보강한다.
