# 서해안 낚시 포인트

인천, 경기, 충남, 전북 서해안 낚시 포인트를 지역, 난이도, 장소 유형으로 찾아보는 정적 웹사이트입니다.

## 기능

- 서해안 낚시 포인트 12곳 카드와 지도형 선택 UI
- 권역, 난이도, 장소 유형, 키워드 검색 필터
- 포인트별 추천 어종, 추천 시간대, 주의사항
- Open-Meteo Marine Weather API 기반 파고·수온 조회
- 국립해양조사원 스마트 조석예보, 지도, 한국관광공사 자료 링크
